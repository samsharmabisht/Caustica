# Changelog

## v0.1.0-preview — 2026-10-28

Initial public preparation build.

- Procedural ocean rendering, generated surface geometry, and quality presets.
- Interactive fine/broad ripple fields, body contact, and particle impacts.
- Sampled buoyancy with editable lift response and separate vertical/horizontal damping.
- Boat controller with Drift, Player, and Autopilot modes.
- Editable thrust, steering, drag, wake, cruise, and camera response curves.
- Paper boat prefab with a two-sided paper material and depth/shadow pass.
- Four example scenes and a 32-second edited 1080p showcase.
- Source attribution and a personal noncommercial project license.
- Fresh Unity 2022.3.62f3 Built-in import and Windows build: 0 errors, 0 warnings.

This preview does not certify every Unity version, pipeline, platform, or hull configuration.
