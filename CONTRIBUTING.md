# Reporting issues and suggesting improvements

For a bug, open a GitHub issue with:

- Unity version, render pipeline, operating system, and graphics API.
- The example scene or component affected.
- Minimal reproduction steps and expected versus actual behaviour.
- The relevant console error and a screenshot or short clip, if useful.

Remove account information, machine paths, keys, and unrelated project files before posting. Share only material you are allowed to publish.

For a feature request, describe the use case and target hardware. Check the [compatibility notes](COMPATIBILITY.md) first so an unimplemented integration is not mistaken for a regression.

Discuss substantial code changes with the maintainer before preparing a contribution. Contributions and forks do not change the [personal project license](LICENSE), and no commercial or redistribution permission is implied.
